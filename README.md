# Snapshot

Snapshot is a clean, modern image-discovery web application built using plain HTML, CSS, and JavaScript. It allows users to quickly search for high-resolution imagery through an intuitive interface.

### Design Decisions:
1. **Category Quick-Pick Chips:** I added clickable preset category pills in the header so users can search popular topics instantly with a single click without typing.
2. **Dark Theme Aesthetic:** I chose a sleek slate dark-mode palette (`#0f172a` background with vibrant sky-blue accents) to give the application a distinct look compared to the standard reference model.
